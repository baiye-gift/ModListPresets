# 模组清单管理 / Mod List Presets

独立伴随模组，适用于 Windows 版《缺氧》。不修改 Mod Updater 的 DLL，不接管其更新功能，可以同时启用。

## 使用

1. 完全退出游戏。将 `dist/ModListPresets` 整个文件夹放到“文档/Klei/OxygenNotIncluded/mods/local”下。
2. 在游戏模组列表启用“模组清单管理 / Mod List Presets”，重启游戏。
3. 再次打开游戏的“模组”页面，点击窗口底部的“模组清单”。新界面使用居中小窗口，并沿用游戏原生控件样式。

开发者安装方式：`./install.ps1` 只安装本地文件；`./install.ps1 -Enable` 另将本工具在原版和眼冒金星模式下启用。安装脚本拒绝在游戏运行时覆盖文件。

### 保存与跨电脑迁移

- 在清单页点击保存按钮，再在弹窗输入名称，保存所有已安装模组的启用状态及完整顺序。名称相同也会创建新的独立文件。
- 保存成功后直接进入预览；“清单操作”中可以导出副本。已有清单从“清单库”点击“预览”进入。
- 将导出的 JSON 和本管理工具安装包复制到另一台电脑。只复制自己的清单和本工具，不包含其他作者模组本体。
- 在另一台电脑点击导入，使用 Windows 文件选择器选择 JSON；也保留路径输入作为备用。导入后先预览，再确认应用。
- 缺失的 Steam 模组有“工坊页面”按钮。缺失项保留在清单中，预览时置灰并自动跳过；安装完成后重新打开清单即可恢复。不同电脑不需要先补齐全部模组才能应用其余项目。
- 按平台和 ID 精确匹配，避免把原版与 FIX 版混为同一个模组。不同名称的本地文件夹不会自动猜测匹配。
- 游戏和模组版本只作提示，不下载、锁定或降级版本。第三方模组的自定义设置不包含在清单中。

### 报错后恢复

- 游戏批量禁用模组不会覆盖手动清单。
- 打开原来保存的清单预览，每个已安装模组只显示明确的“启用”或“停用”，表示应用后的最终状态，可以在应用前直接切换。摘要将“应用后状态”和“本次变化”分开显示。
- “查看”下拉菜单包含全部、应用后启用、应用后停用和缺失。“批量设置”下拉菜单包含按清单原状态、全部启用和全部停用；这些调整只影响本次预览。
- 清单中需要启用但尚未安装的模组会标为“缺失 · 自动跳过”，不提供启用勾选，也不会阻止应用或触发部分写入。它仍保留在保存的清单中；以后安装好模组再打开原清单，就会重新按清单状态恢复。
- 清单外的已启用模组会停用但不会卸载；清单内的已安装模组按清单顺序排列，其他模组保持相对顺序排在末尾。
- 本管理工具自身保持启用，以免导入另一台电脑的清单后失去恢复入口。
- 如果本工具也被游戏禁用，先手动启用本工具并重启，再恢复其他模组。游戏安全模式下不会绕过游戏的保护机制。
- 另一游戏模式的清单不能直接应用。
- 应用后关闭清单窗口，并退出游戏原生模组页面，按游戏提示重启。没有 DLL 热加载。

### 输入序号排序

进入“当前模组 / 顺序”，从“查看”下拉菜单选择全部、已启用或已停用，再搜索名称或 ID。在右侧输入目标序号，按回车或点击“移动”确认。其余项目自动顺移，保留搜索及滚动位置；仅离开输入框不会提交。序号从 1 开始，对应完整加载列表；筛选和搜索不会重新编号。右侧滚动条支持拖动滑块和点击轨道快速翻页。游戏原有拖动排序保持可用。

### 删除清单

先从清单库预览要处理的清单，再从“清单操作”下拉菜单选择删除。按钮下方的小确认卡会显示清单名称；删除只作用于清单库中的这一份 JSON，不改变当前游戏模组和其他清单。上一份自动备份不提供删除选项。

### 可选自动备份

位于“设置”下拉菜单，**默认关闭**。打开后，每次在本工具中应用清单或移动序号之前，将当前状态保存到 `previous.json`，只保留上一份。

- 不监控其他模组或游戏的写入，不在每次启动时自动备份，不覆盖手动保存的清单。
- “恢复上一份备份”先进入预览，需要再确认应用。
- 关闭开关不会删除已有备份。开关设置存储在 `settings.json`。
- 安装脚本启用本工具前的配置备份属于安装回退文件，与这个运行时开关分开。

## 数据位置

位于游戏自己的模组目录：

```text
文档/Klei/OxygenNotIncluded/mods/config/ModListPresets/
  presets/       手动保存及导入的清单
  exports/       导出清单
  settings.json  自动备份开关
  previous.json  可选的上一次操作前备份
```

手动清单是 UTF-8 JSON，含格式版本、名称、UTC 保存时间、游戏版本、原版/眼冒金星模式、模组来源/ID/版本/启用状态。数组顺序就是加载顺序，不包含本机绝对安装路径。

## 开发

源码及构建全部位于此目录，不修改游戏程序集或工坊原版。`reference/` 仅供本地检查接口，`tools/` 仅供开发，不放进发布包。

```powershell
./build.ps1 -GamePath 'D:\steam\steamapps\common\OxygenNotIncluded'
./test.ps1 -GamePath 'D:\steam\steamapps\common\OxygenNotIncluded'
```

使用 Windows 自带 .NET Framework C# 编译器，引用本机游戏程序集。安装包仅有一个 DLL 和两个 YAML 文件，无额外 PLib 或 Harmony 副本。

界面复用游戏原生 Klei/TMP 控件，无需 Mod Updater 或 PLib 依赖。筛选、批量、设置和清单操作使用锚定在按钮下方的小菜单，保存名称与导入路径才使用居中输入窗口。启用状态通过游戏 `SetEnabledForActiveDlc` 修改，批量变更后调用游戏 `Manager.Save`，退出页面沿用游戏原生重启检查。Windows 文件选择器使用系统 comdlg32，无额外 WinForms 依赖，取消选择不会修改配置。

写入手动清单/设置使用同目录临时文件后原子替换；游戏配置保存失败时尝试恢复操作前的内存列表与磁盘内容。删除功能只接受清单库根目录内的 JSON 文件。JSON 不启用类型反序列化，限制文件 4 MB、2000 个项目，并校验来源、ID、重复项目和模式。

## 卸载

在游戏里禁用本工具并正常退出，再移走 `mods/local/ModListPresets` 文件夹即可。手动清单位于独立配置目录，可保留。不要用旧的整份 `mods.json` 覆盖后来新增的其他模组配置，除非明确需要回滚全部配置。
